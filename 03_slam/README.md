# 03_slam — 定位与建图

## 职责

在**没有 GPS、没有外部摄像头的室内场地**里，给控制系统提供 ≤10cm 级的位置与航向，
让无人机知道自己在 9×7 网格的哪一格、离航线偏了多少。

## 硬约束（决定方案边界）

- 无人机以外**不得有其他摄像头**（赛题说明 1(6)）。
- 若用辅助定位装置，**必须放在地图区域及其上方空间之外**（赛题说明 1(7)）——UWB 锚点、外部标记、反光标靶都不能吊在地图上方。
- 可用线索：巡查区上方长边、右侧短边各一条 **1.8cm 黑线**（说明 1(6)）；地面 50cm 灰色虚线网格（线宽仅 0.05cm，很难直接探测）。
- 高度 120±10cm，视角固定向下，画面尺度变化小。

## 候选方案（待评估）

| 方案 | 优点 | 风险 |
|---|---|---|
| 下视相机 + 黑线/网格线检测 | 只用机载相机，天然对齐地图坐标系 | 0.05cm 虚线太细，主要靠 1.8cm 黑边；光变与阴影干扰 |
| 2D 激光雷达 + 扫描匹配 | 不依赖纹理，航向稳 | 120cm 高度扫地面网格可能扫不到；地面是哑光喷绘布，反射弱 |
| 视觉标签 / AprilTag（贴在地图外围） | 精度高、易实现 | 标签是否属于"改变测试环境"需谨慎，且要贴在地图区域内侧才行 |
| UWB / 超声信标 | 不依赖视线 | 锚点必须在地图区域及上方空间之外，几何构型差、精度可能不够 ±10cm |
| 光流 + IMU 里程计 | 无需外部设施 | 累积漂移，需要地图约束做回环校正 |

> 现实做法通常是**组合**：下视视觉给绝对格点约束，IMU/光流给短时平滑，二者松耦合。

## 需要先回答的问题

1. 定位基准坐标系选哪个（地图左下角格点 / 第一条黑线）？
2. 允许在地图外围（安全网外）放置什么装置？现场是否允许提前布置？
3. 精度是否够 10cm 级——先做静态打点实测，再谈滤波器。
