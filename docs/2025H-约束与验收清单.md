## 2. 可直接量化的"推论指标"（供设计目标用）

| 项目 | 推论值 | 依据 |
|---|---|---|
| 需覆盖格数 | 63 − 3 = **60 格** | 禁飞区占 3 格 |
| 定位误差预算（不偏格） | 建议 ≤±15cm | 格宽 50cm、光斑仅需落在格内，保守取 1/4~1/3 格 |
| 轨迹偏差（不被判偏航） | 建议 ≤10cm（RMS） | "轨迹与航线不一致即偏离"是连续判据 |
| 单程航程 | 约 35~40m（估算） | 7 行 × 4.5m + 6 次 0.5m 转场 ≈ 34.5m，加禁飞区绕行 |
| 所需巡航速度 | ≥0.25 m/s | 300s 内跑完 35~40m，且要为识别/减速留余量 |
| 动物地面尺寸 | 象长 30cm，其余约 15cm（2:1:1:1:1） | 原文说明 1(4) |
| 120cm 高度成像（估算） | 垂直 FOV 60° → 地面视场约 1.4m，约 1.3mm/px（1080p）；象约 230px、其余约 115px | 假设 FOV 与分辨率，实际按相机标定复核 |

> 结论：**分辨率不是瓶颈，稳定性才是**——运动模糊、曝光跳变、地图形变、机身倾斜导致目标中心偏移，才是识别与打点误差的主因。

## 3. 主要扣分/失分点（按影响排序）

1. 漏格或偏航 → 直接扣分，且"光斑扫到格内"才算覆盖，所以**激光光斑位置 = 实际航线**，必须与屏幕画出的航线一致。
2. 地面站不能是 PC：所有界面、按键、存档、回看都要自己做，工程量容易被低估。
3. 识别要求"种类 + 数量 + 所在格"，单帧检测不够，需要**跨帧归并到格**，否则重复计数。
4. 发挥部分的"光斑打在动物轮廓上"需要闭环，纯开环按坐标打点会因机身漂移打偏。
5. 45°±5° 俯角降落：不是垂直降落，需要位置-高度协同轨迹，且落点中心不能出红区。
6. 单次测试不许换电池：续航与功耗预算要留足（含机载计算板）。

## 4. 现场测试流程（复现用）

1. 赛区铺图 → 抽签定禁飞区代码 → 贴灰色禁飞布。
2. 抽签定动物图片与所在格 → 队伍自行粘贴（方向自定）。
3. 队员戴护目镜/手套/长袖长裤。
4. 无人机手动放到红色起飞区 → 一键起飞，交付外部启动/急停装置（若有）。
5. 飞行全程无干预；≤300s 完成巡查 + 降落。
6. 评委核对：偏航/漏格、地面站实时显示与存档回看、汇总数量、光斑是否在动物轮廓上、降落俯角与落点。
7. 可测两次，取综合成绩高的一次；换电 ≤2min。
