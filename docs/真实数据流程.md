# 真实数据流程（主路线）

> 结论先说：**合成集只用来打通链路和做兜底，正式训练用实拍图。**
> 我们踩过的坑证明这条路必须走：800 张合成图其实只来自**一张场地**（8 只动物：
> 4 孔雀 / 2 虎 / 1 猴 / 1 象 / **0 狼**），结果模型把狼判成孔雀、
> 孔雀占 45% 变成"默认类"、陌生纹理也塌缩成孔雀，而 mAP 还显示 0.99。

## 1. 目录约定

```
datasets/                     # 已被 .gitignore 忽略，不进仓库
├── raw/                      # 赛题附件原图（动物体态 / 地貌图）
├── real/                     # ★ 实拍数据集（prepare_real.py 生成）
│   ├── images/{train,val}/*.jpg
│   ├── labels/{train,val}/*.txt     YOLO 格式：cls cx cy w h（0~1 归一化）
│   └── summary.json                 每类实例数，训练前先看它
└── yolo_synth/               # 合成数据集（辅助 / 兜底）
```

配置：`01_vision/configs/data_real.yaml`（主）、`data_synth.yaml`（辅）。

## 2. 拍什么、怎么拍

| 项目 | 建议 |
|---|---|
| 高度 | **1.2m**（和赛题 120cm 一致），手持或架高都行 |
| 角度 | 俯视为主（机载相机是垂直向下），再补 20~30% 的斜视/侧光 |
| 光照 | 开顶灯拍，也拍几张窗边逆光、阴影里的（赛题说明 1(8)：光照不可控） |
| 每张目标数 | 1~3 只，**别摆太密**（真实场地 60 格一般贴 5~10 只） |
| 目标尺寸 | 象 30cm、其余 15cm，用 `scripts/make_print_sheet.py` 打印的靶标 |
| 背景 | 打印好的地貌图（没有就用地面/桌面，但要**混着拍**，别只拍一种桌面） |
| **负样本** | **20~30% 的图不放动物**（空地面、纸边、阴影、电线、鼠标垫这类纹理） |

> 负样本不是"凑数"，它是抑制误检最有效的手段。我们记录的误检（绿色迷宫鼠标垫
> → peacock 0.56）就是典型：模型从没见过"无目标的真实纹理"。

## 3. 打标规范

- 类别顺序（**必须和 `configs/classes.txt` 一致**）：
  `0 peacock 孔雀 / 1 wolf 狼 / 2 monkey 猴 / 3 elephant 象 / 4 tiger 虎`
- 框紧贴动物**外轮廓**（含白纸边就别框进去，框到彩色部分即可）
- 被画面边缘截断的也标（框跟着截断），模型要能处理半只
- **没有目标的图：留一个空的同名 .txt**（不要不建文件，也不要把图删掉）
- 工具随便：labelImg / X-AnyLabeling / Label Studio 都行，导出 **YOLO txt**

## 4. 三步走

```powershell
# ① 整理 + 划分（图片和 txt 放同一个目录，或 images/ + labels/ 都支持）
python 01_vision/scripts/prepare_real.py --src D:\photos --val-ratio 0.2

# ② 体检（任何一类 0 实例、图/标签对不上、框越界都会直接失败）
python 01_vision/scripts/check_dataset.py

# ③ 训练（300 张建议 150 轮，小数据集要多训）
python 01_vision/scripts/train.py --device 0 --epochs 150 --batch 16 --workers 8
```

体检不过就别训——`check_dataset.py` 的退出码是 1，能直接卡在流水线里。

## 5. 300 张的量级怎么训

| 参数 | 建议 | 理由 |
|---|---|---|
| epochs | **150** | 300 张数据少，60 轮往往还没收敛 |
| batch | 16 | 8GB 显存够；OOM 降到 8 |
| imgsz | 640 | 与部署一致，别在训练时改 |
| patience | 40 | 早停放宽一点，小数据集曲线抖 |
| mosaic / mixup | 默认开 | 小数据集靠增强补多样性 |
| 冻结 | 不用 | 数据少但域差异大，冻结 backbone 会学不动 |

参考：300 张 × 150 轮，RTX 5070 Laptop 大约 **10~15 分钟**。

## 6. 训完怎么验

```powershell
# 看预测图 + 各类检出数
python 01_vision/scripts/predict_demo.py --limit 12

# 拿没参与训练的新照片做对比（同一批靶标、不同光线/角度）
python 01_vision/scripts/verify_real.py --images D:\photos_test --init-labels
# 填好 labels.csv 后
python 01_vision/scripts/verify_real.py --images D:\photos_test --labels D:\photos_test\labels.csv
```

`summary.json` 里看三个数：**每类 MAE、完全一致图占比、漏检/多检图数**。

## 7. 什么时候还要用合成集

- 显存/时间充裕时，把合成集**混进**训练（`datasets/yolo_synth` + 实拍），
  能补"俯视 1.2m、机身偏航、运动模糊"这些实拍不容易凑齐的角度；
- 但比例别超过 1:1，且**必须**确认 `check_dataset.py` 在实拍集上通过。

合成集生成（辅助）：

```powershell
python 01_vision/scripts/synth_dataset.py --n-train 1200 --n-val 150 --scenes 40
```

`--scenes` 必须给足（默认 40）。给 1 就等于"整个数据集只有一张场地"，就是上面那个坑。
