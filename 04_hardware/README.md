# 04_hardware — 机体与载荷

## 硬约束

| 项目 | 要求 |
|---|---|
| 轴距 | ≤45cm |
| 桨叶 | **必须全防护**，否则不予测试 |
| 激光笔 | 垂直向下安装，地面光斑直径 ≤1cm |
| 供电 | 单次测试全程不换电池（含机载计算板 + 相机 + 激光） |
| 激光笔 | 红色激光笔在 2025 器材清单内；注意功率与安全（测试需护目镜） |
| 地面站 | MCU + ≥6 吋屏 + 按键，不允许 PC（见 `05_ground_station/`） |

## 结构要点

- **激光笔光轴与相机光轴要标定**：光斑在画面中的固定像素位置（或离线标定的偏移表），否则"打动物轮廓"没法闭环。
- 激光笔安装必须可调：机身有配平误差时，靠机械微调保证"垂直向下"。
- 桨保会增加重量与阻力，续航预算要一起算。
