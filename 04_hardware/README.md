# 04_hardware — 机体与载荷

## 硬约束

|项目|要求|
|---|---|
|轴距|≤45cm|
|桨叶|**必须全防护**，否则不予测试|
|激光笔|垂直向下安装，地面光斑直径 ≤1cm|
|供电|单次测试全程不换电池（含机载计算板 + 相机 + 激光）|
|激光笔|红色激光笔在 2025 器材清单内；注意功率与安全（测试需护目镜）|
|地面站|MCU + ≥6 吋屏 + 按键，不允许 PC（见 `05_ground_station/`）|

## 接口与连线要点

|链路|接法|备注|
|---|---|---|
|NEO 4 ↔ 飞控|DroneCAN，接 X7+ 的 `CAN1` / `CAN2`（CUAV 推荐 `CAN1`）|PX4 参数：`UAVCAN_ENABLE` = `Sensors Automatic config`，`UAVCAN_SUB_GPS` = `Enable`，改完重启|
|飞控 ↔ 机载计算机|X7+ 串口 / 以太网 → 鲁班猫，跑 MicroXRCEAgent|打通 `/fmu/*`，见 `02_control_ros2/README.md`|
|机载计算机 ↔ 相机|鲁班猫 CSI 或 USB|下视安装，光轴要和激光笔一起标定|
|MID-360 ↔ 机载计算机|100BASE-TX 以太网直连鲁班猫|9~27V 直接取电（常温 6.5W，低温自加热峰值可到 14W）；时间同步用 **PTPv2**（IEEE 1588），室内没有 GPS 授时可依赖|
|供电|单电池供动力 + 鲁班猫 + MID-360 + 相机 + 激光笔|鲁班猫（RK3588）和 MID-360 都别和飞控共用一路，峰值功耗要单独算并留余量，别掉电重启|

## 结构要点

* **激光笔光轴与相机光轴要标定**：光斑在画面中的固定像素位置（或离线标定的偏移表），否则"打动物轮廓"没法闭环。
* 激光笔安装必须可调：机身有配平误差时，靠机械微调保证"垂直向下"。
* 桨保会增加重量与阻力，续航预算要一起算。
* NEO 4 是磁罗盘载体：远离电调/电源线和大电流走线，装在机体上表面并做磁校准，否则航向会飘。
* **桨叶/桨保会挡雷达视野**：MID-360 水平 360°，装在桨盘高度上会被桨叶扫出一圈固定残影；
尽量顶装、让 -7° 以下方向无遮挡，上机后看点云里有没有固定"桨叶环"，必要时补遮罩或裁剪点云。
