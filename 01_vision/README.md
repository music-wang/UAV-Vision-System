# 01_vision — 机载视觉

## 职责

1. **检测**：在机载相机画面中检出 5 类动物（象 / 虎 / 狼 / 猴 / 孔雀），输出类别 + 置信度 + 框。
2. **归格**：把画面目标投射到地图坐标，换算成 `AnBm` 格号。
3. **计数**：跨帧、跨格去重，输出"某格 × 某类 × N 只"的事件流，而不是逐帧报警。
4. **打点（发挥部分）**：给出激光光斑相对动物轮廓的偏差，供控制环闭环微调。

## 边界

- **只允许机载摄像头**（赛题说明 1(6)），地面上不能再架相机做辅助。
- 地面站没有 PC（赛题一、二.1），所以视觉结果必须自己编码下发，不能依赖上位机程序。
- 光照不可控：顶灯、窗外光、照明不均、地图色差都要能扛（赛题说明 1(8)）。

## 关键指标（推论，见 `docs/2025H-约束与验收清单.md`）

| 项目 | 目标 |
|---|---|
| 单类召回 | 地图上粘贴的动物必须一只不漏（漏检 = 统计错） |
| 数量正确率 | 同格同类多只时可区分个体，不重复计数 |
| 实时性 | 满足 300s 全程 + 巡航 ≥0.25m/s |
| 归格误差 | ≤±15cm（等价于不跨格误判） |

## 目录

| 路径 | 说明 |

| `assets/` | 赛题附图的可用化素材：15 张去底动物模板 + 地貌图缩略图（见 `assets/README.md`） |
