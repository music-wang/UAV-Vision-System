| 路径 | 说明 |
|---|---|
| `templates/<species>/<species>_<1..3>.png` | 15 只动物（每类 3 种姿态），去底带 alpha，长边 900px，合计约 8.7 MB |
| `terrain_preview.jpg` | 地貌图缩略图 1600×1280（文档/自检用，约 0.6 MB） |

重新生成：

```powershell
python 01_vision/scripts/split_templates.py `
  --sheet datasets/raw/动物体态.png `
  --terrain datasets/raw/地貌图.png `
  --out 01_vision/assets
```

## 三个必须先知道的事实

1. **地貌图 = 整幅 500cm×400cm。** 11811×9449 px @600dpi 正好等于 500mm×400mm。
   所以图上的四边就是喷绘布四边，**巡查区 450cm×350cm 是居中内缩 25cm 的那块**，
   换算关系：1 px = 500/11811 mm ≈ 0.0423 mm。

2. **图里没有网格、没有黑线、没有动物。** 50cm 灰色虚线（线宽 0.05cm）、
   上方长边与右侧短边两条 1.8cm 黑线、以及动物贴纸，都是**赛区打印/测试时才加上去的**。
   这意味着：拿这张图当背景训练，模型永远见不到网格线和黑线；
   拿白底插图训练，模型只见过白底。**训练集必须自己合成**（贴动物 + 画网格 + 加黑线 + 光照/色偏/模糊）。

3. **动物是"透明底 + 近乎全透明白背景"的手绘插图（alpha≈1），不是照片。**
   直接白底训练会在真实喷绘布上翻车（背景是森林/河流/干裂地，纹理极强）。
   合成时必须贴到 `terrain_preview.jpg` 同源的高清地貌图上，而不是贴到纯色背景。

## 关于白色描边

切分时保留了动物边缘约 1px 的浅色描边没有过度清理：**真实场地上的动物是沿轮廓剪下来的
纸质贴纸，本身就有白纸边**，留一点点边反而更贴近实拍。合成时如果想更"硬"，可以把模板
再用形态学腐蚀 1~2px。

## 尺寸比例（合成时必须遵守）

赛题说明 1(4)：象 : 虎 : 狼 : 猴 : 孔雀 = **2 : 1 : 1 : 1 : 1**，象长 30cm，其余约 15cm。
合成时请按地面真实尺寸（cm）折算像素，再由相机内参换算成图像尺寸，
不要在像素空间随意缩放，否则模型学到的尺度先验是错的。
